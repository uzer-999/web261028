이번 영화 평점 통계 실습을 진행하면서 ChatGPT를 활용해 자바스크립트의 기초 개념을 이해하는 데 도움을 받았다. 코드는 직접 작성하였으며, 작성 과정에서 이해하기 어려웠던 자바스크립트의 문법과 사용 방법에 대해 질문하고 설명과 예시를 참고하였다.

특히 const와 let을 이용한 변수와 상수 선언, 배열을 이용해 영화 제목과 평점, 개봉 연도를 관리하는 방법, for 반복문과 if 조건문을 활용해 평균과 최고 평점, 8점 이상인 영화의 개수를 구하는 원리를 알아보았다. 또한 console.log()로 결과를 콘솔에 출력하는 방법과 템플릿 리터럴을 이용해 alert() 창에 요약 결과를 표시하는 방법도 이해할 수 있었다.

모르는 부분을 바로 코드를 대신 작성하게 하기보다는 개념과 예시를 질문하고, 이를 바탕으로 직접 코드를 작성하면서 문법이 실제로 어떻게 작동하는지 확인하려고 노력했다. 이 과정에서 HTML과 CSS로 구성된 기존 영화 보드에 자바스크립트를 연결하면 데이터를 계산하고 결과를 출력할 수 있다는 점도 배웠다.

이번 실습을 통해 자바스크립트의 기본 문법뿐만 아니라 반복문과 조건문을 활용해 데이터를 처리하는 방법을 익힐 수 있었다. 앞으로도 ChatGPT를 모르는 개념을 질문하고 이해를 돕는 학습 도구로 활용하되, 코드는 스스로 작성하고 실행 결과를 확인하면서 프로그래밍 실력을 키워 나가고 싶다.
